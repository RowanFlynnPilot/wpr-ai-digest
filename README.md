# wpr-ai-digest

Friday-morning email of new AI tools and features with concrete applications for Wausau Pilot & Review.

1. Create the repo and push these files.
2. Add three Actions secrets: `ANTHROPIC_API_KEY`, `SMTP_USER`, `SMTP_PASSWORD` (see CLAUDE.md).
3. Actions → *Weekly AI digest* → **Run workflow** to send a test immediately.
4. Edit `context.md` whenever the project list or priorities change.
