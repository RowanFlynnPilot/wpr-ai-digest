# Who this digest is for

Rowan Flynn, technical lead at Wausau Pilot & Review (WPR) — solo developer running a 40+ repo fleet of Python scrapers, Supabase backends, React/Vite widgets, and GitHub Actions crons, built almost entirely with Claude Code. This is a weekly radar of Claude skills (SKILL.md packages) and Claude Code plugins that are new or trending, filtered against the skills already installed on Rowan's machine — the list of those is provided below and must never be surfaced.

# How to rank and pitch

Rank by how much a skill would speed up or improve WPR's actual work: scraping and anti-bot, PDF and document extraction, data cleaning and record linkage, Supabase/Postgres, React/Vite widgets, GitHub Actions, email and newsletter tooling, data viz and mapping, civic-data and journalism workflows, testing and code review. Momentum counts — a skill gaining stars or being widely shared this week beats an obscure one — but usefulness to this stack counts more. Every application must name the WPR workflow or repo type it would help. Put the install path in the access field (e.g. "open-source · /plugin install …" or "clone into ~/.claude/skills"). Fetch the skill's repo or SKILL.md before including it to confirm it is real, maintained, and actually a skill rather than a prompt dump.

# Worth surfacing

- New or newly popular skills in Anthropic's official skills repository and Claude Code plugin marketplaces
- Community skills and plugins trending on GitHub (stars, forks, recent activity) or widely shared on Hacker News, Reddit, X, or developer newsletters this week
- Skills for the categories above — especially scraping, document AI, data pipelines, Supabase, React, GitHub Actions, and data journalism
- Materially updated skills whose new capabilities matter (only if the update is genuinely significant)
- Skill-building tooling: notable changes to how skills are authored, tested, or distributed

# Not worth surfacing

- Anything on the installed list below, or a trivial variant or fork of it
- Anthropic's built-in skills, which are always available and never news: docx, pptx, xlsx, pdf, claude-api, mcp-builder, skill-creator, web-artifacts-builder, theme-factory, canvas-design, algorithmic-art, doc-coauthoring, dataviz, design, artifact-design, artifact-diagramming, code-review, security-review, simplify, schedule, loop, init, run, update-config, keybindings-help, workflow-authoring, morning, explain-usage, consolidate-memory, import-memory, setup-cowork
- Generic prompt packs, "100 prompts" collections, or skills with no real instructions or tooling
- Abandoned repos, skills without a SKILL.md, or anything that cannot be confirmed to exist
- Skills for stacks WPR doesn't use (mobile, game dev, enterprise Java, etc.) unless the idea transfers directly
- Anything already listed under "already covered"
