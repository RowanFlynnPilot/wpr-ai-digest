# Who this digest is for

Rowan Flynn and the editor at Wausau Pilot & Review (WPR), a nonprofit local newsroom in Wausau, Wisconsin. This is a weekly radar of new and trending AI tools and plug-ins — what launched, what's gaining momentum, what's worth trying. Written for a general reader running a small operation, not a developer. Companion digests already cover developer tooling tied to WPR builds (Fridays) and AI news across the local-journalism industry (Mondays); this one is the general tools radar.

# How to rank and pitch

Rank by a blend of momentum (genuinely new, or visibly trending this week) and practical usefulness to a two-person newsroom team. Pitches in plain language — no API or SDK jargon. Applications should say what a small team would actually do with the tool in a normal work week — writing, editing, research, interviews, transcription, images, spreadsheets, email, scheduling, the WordPress site — not integration or coding work. Always state real pricing: free tier limits, monthly cost, or open-source.

# Worth surfacing

- Newly launched or materially updated AI apps and services someone can sign up for and use the same day: writing and editing, research assistants, transcription and meeting notes, image/video, spreadsheets, presentations, note-taking
- Plug-ins and extensions: WordPress plugins (the WPR site runs WordPress), browser extensions, Google Workspace and Microsoft 365 add-ons, Slack and Zoom apps
- Tools with visible momentum this week: topping Product Hunt, GitHub trending, or Hacker News; sudden broad adoption or word-of-mouth
- No-code automation and agent tools that connect everyday apps (Zapier-style workflows, desktop agents) usable without writing code
- Meaningful AI feature updates inside tools a small team likely already uses: Google Workspace, Microsoft 365, Canva, Zoom, Notion, Grammarly and the like
- Free tiers, nonprofit discounts, and open-source alternatives to paid tools

# Not worth surfacing

- Developer SDKs, APIs, models, and coding tools — the Friday project digest covers those
- Journalism-industry news, programs, grants, and case studies — the Monday industry digest covers those
- Enterprise-only products, waitlist-only launches, or announcements with nothing usable today
- Crypto/web3 tools, engagement-bait growth tools, or anything a newsroom would be embarrassed to be seen using
- Anything already listed under "already covered"
