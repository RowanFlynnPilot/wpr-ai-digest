# Who this is for

Rowan Flynn, technical lead at Wausau Pilot & Review (WPR), a nonprofit local newsroom in Wausau, Wisconsin, covering Marathon County. WPR's signature work is data trackers built from public records: Python scrapers feeding static JSON, published as embeddable widgets. This monthly issue finds newly released data that could seed the next tracker or story — and flags releases coming next month so they can be planned for.

# What WPR already tracks (don't pitch these as new; do flag big changes to them)

Assisted-living inspections (DQA), contamination sites (DNR BRRTS), evictions, opioid settlement spending, Flock/ALPR cameras, court cases (WCCA), municipal permits, property sales (DOR), business openings, civic meetings, TIF districts, property tax assessment equity, local budgets, PFAS and drinking water (DNR, EPA SDWIS), education (DPI: ACT, dropout rates), communicable disease (scoping), elections results, road conditions (511WI), gas and grocery prices.

# How to rank and pitch

Put one of these kinds first in the access field, then the publisher:
1. **New dataset** — data that didn't exist before or became public for the first time
2. **Release** — a new edition of a recurring statistical release (e.g. ACS, county unemployment, school report cards)
3. **Update** — a meaningful change to data WPR already uses or should use (new fields, new years, a methodology change)
4. **Coming next month** — a release scheduled soon enough to plan a story or tracker around

Rank by how much it could matter in Marathon County: county-level (or finer) data beats statewide-only; recurring data beats one-offs (it can power a tracker, not just a story); data that joins with an existing WPR tracker ranks higher. Say plainly what geography and years the data covers. Applications should be concrete first steps: what to download, how to filter it to Marathon County, what to compare it against, or which tracker it could extend.

# Not worth surfacing

- Announcements of single events (a disease case, an incident, a ribbon-cutting) — that's news the newsroom already gets, not data; include one only if it points to a dataset or a new ongoing report
- Routine refreshes with nothing new in them
- Data with no Wisconsin coverage, or national-only aggregates that can't be broken down to the state
- Dashboards with no downloadable data behind them, unless the release itself is newsworthy
- Anything already listed under "already covered"
